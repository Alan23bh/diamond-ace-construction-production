# Phase 4 — Our Approach

Phase 4 replaces the remaining legacy-dark Our Approach page with the approved Diamond Ace V2 visual language.

## Page Flow

1. Static-image hero with clear estimate and process CTAs
2. Four approach highlights: scope, scheduling/access, prep/protection, and handoff
3. Six-step working process from estimate request through final review
4. Dark preparation feature with large service-context photography
5. Four pre-work clarity items
6. Property-context feature for occupied spaces, vacant/turnover units, and property-management work
7. Brass estimate CTA

## Content Rules

- Display headings use Title Case.
- Stock imagery is used only as service-context imagery and is never described as Diamond Ace project photography.
- The process explains how a request typically moves forward without making unsupported guarantees about exact timing or scope.
- The page stays centered on painting, apartment turnovers, drywall/texture repair, and exterior painting.
