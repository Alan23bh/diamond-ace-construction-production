# Phase 3 — Services Page Redesign

Phase 3 replaces the remaining V1 dark Services page with the light, editorial visual system established on the approved homepage.

## Page Structure

1. Static image service hero with a dark readability overlay and primary estimate CTA.
2. Four-service quick navigation strip.
3. Four detailed alternating service features:
   - Apartment Turnovers
   - Interior Painting
   - Drywall Repair & Texture
   - Exterior Painting
4. Dark preparation and finish section using existing service-context photography.
5. Common project scenarios section.
6. Service FAQ using native accessible `details` and `summary` elements.
7. Brass estimate CTA before the global footer.

## Design Direction

The page borrows layout principles from the Laser Photonics references supplied during design research: large imagery, strong heading hierarchy, alternating editorial sections, selective dark contrast, useful supporting lists, FAQ content, and clear conversion points. It does not copy their product-site length, branding, or technical content.

## Content Rules

- Display headings use Title Case.
- Normal paragraphs use sentence case.
- Stock imagery is service-context imagery and is not represented as Diamond Ace project photography.
- Only the four approved Diamond Ace services are advertised.
- The page does not claim remodeling, flooring, roofing, cabinet installation, or other unsupported work.
